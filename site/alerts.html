Alerts & Dialogs

Practice handling JS dialogs, custom modals, and toast notifications

page.on('dialog')

1. JavaScript Alert

Triggers window.alert() — use page.on('dialog', d => d.accept())

alert
In Playwright: page.on('dialog', dialog => dialog.accept()) then click the button.

2. JavaScript Confirm Dialog

Triggers window.confirm() — can accept or dismiss

confirm
Accept: dialog.accept()   |   Dismiss: dialog.dismiss()

3. JavaScript Prompt Dialog

Triggers window.prompt() — enter a value then accept

prompt
In Playwright: page.on('dialog', d => d.accept('your text'))

4. Delayed Alert (after 3 seconds)

Alert fires after a delay — tests that your dialog handler is set up before the alert appears

timing
Register page.on('dialog', ...) BEFORE clicking — the handler persists for future dialogs.

5. Custom CSS Modal Dialog

Not a JS dialog — a CSS/HTML modal overlay. No page.on('dialog') needed.

modal
Use locators to find modal content, click the close button or action buttons.

6. Toast Notifications
